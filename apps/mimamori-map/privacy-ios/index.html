いまどこシェア iPhone 版 プライバシーポリシー

「いまどこシェア」の iPhone 版(以下「本アプリ」)は、あらかじめ承認し合った相手とだけ、あなたが共有をオンにしている間、位置・電池の残り・メッセージを共有するアプリです。このポリシーでは、本アプリが取得する情報、使う目的、保存先、保存期間、削除の方法を説明します。

1. 取得する情報と、使う目的

2. 情報の保存先と、第三者の関与

  • iPhone の中だけのもの以外は、Google の Firebase(Authentication・Cloud Firestore)に保存・処理されます。Google は、運営者の指示に基づいて情報を処理するサービス提供者です。データの保存場所: Cloud Firestore: 東京(asia-northeast1)。Android 版の「いまどこシェア」と同じ仕組みで、Android 版を使う相手ともつながれます。
  • 不正な利用を防ぐため、Firebase の App Check(Apple の DeviceCheck)を使います。Apple の仕組みで、リクエストが正規のアプリから来ていることを確かめ、その結果のトークンを Firebase へのリクエストに付けて送ります。この目的で、位置やメッセージを送ることはありません。
  • 位置は、iPhone の位置情報サービス(Apple の Core Location)を通じて取得します。
  • 地図の表示には、Apple のマップを使います。地図を表示するとき、表示する範囲の地図のデータを Apple から受け取ります。
  • 運営者が設置した中継のプログラム(Google の Apps Script)が、毎日、解除されたつながりのメッセージ・位置や、期限が切れた招待コードを、サーバーから削除します。
  • あなたがメッセージを送ったあと、相手の Android の端末に新着を通知するため、本アプリは中継に、メッセージの識別子・つながりの識別子・本人確認用のトークンを知らせます。中継は、サーバーで内容を確かめてから、相手の端末への通知を Firebase Cloud Messaging に依頼します。メッセージの本文や位置は、中継には送りません。通知に載るのは、送り主の表示名とつながりの識別子だけです。iPhone には、この版ではプッシュ通知は届きません。
  • 「Apple でサインイン」「Google でログイン」は任意です(メールアドレスとパスワードでも使えます)。Apple・Google が本人確認をし、メールアドレスと識別子を認証サービス(Firebase Authentication)に渡します。Apple には名前を求めません。認証サービスは、Google が渡す名前とプロフィール画像の URL を、ログインの記録として保持することがありますが、本アプリはそれらを画面にも相手にも使いません。
  • 上記の事業者を除き、あなたの情報を第三者に提供・販売することはありません。法令に基づく開示の求めがあった場合は、法令に従って対応します。
  • 本アプリは、上記の Firebase・Apple の部品を組み込んでいます。これらの部品は、それ自身の動作のために Google や Apple と通信することがあります。その内容は、こちらでは確認できていません。
  • 通信は暗号化されます(TLS)。サーバーから取得した情報は、本アプリのメモリにだけ置き、iPhone の記憶領域には保存しません。移動の記録は、iCloud などのバックアップの対象外にしています。

3. 位置情報の取り扱い(重要)

  • 位置は、承認済みの相手ごとに、あなたが「この人と位置を共有する」をオンにしたときだけ共有します。相手の承認と、あなた自身の同意の両方が必要です。
  • 位置情報の許可を求める前に、何を・誰に・いつ送るかを画面で説明します。まず「アプリの使用中は許可」を、そのあと説明の画面をはさんで「常に」をお願いします。「常に」を選ばなくても、アプリが動いている間は共有できます。
  • 本アプリを閉じている間に位置を使っているときは、iPhone の画面の上部に位置情報の表示が出ます。隠しモードはありません。
  • 共有をオフにすると、相手には「共有オフ(本人の操作)」と伝わります。オフにするときに、相手の画面から最後の位置を消すこともできます。
  • 位置の共有と移動の記録は、別々のスイッチで、それぞれ独立してオン・オフできます。共有も記録もオフのときは、位置を取得しません。

4. 保存期間と削除

  • 位置・電池・共有の状態: 最新の1件だけを保存し、更新のたびに上書きします(履歴は保存しません)。共有をオフにして最後の位置を消したとき、つながりを解除したとき、アカウントを削除したときに削除されます。相手につながりを解除された場合、あなたの最後の位置は、あなたがその後に本アプリを開いたとき、または毎日の自動の掃除で削除されます。
  • メッセージ: あなたが削除するまで保存します。あなたが送ったメッセージは、いつでも削除でき、相手の画面からも消えます。つながりを解除すると、双方ともメッセージを読めなくなり、そのつながりのメッセージは、毎日の自動の掃除でサーバーから削除されます。
  • 招待コード: 10分で無効になります。使われたコードは、発行した人が承認・拒否・解除したときに削除します。それ以外のコードは、発行した人が取り消したとき、次にアプリを開いたとき、または毎日の自動の掃除で削除されます。
  • 移動の記録(iPhone の中): 保存期間を7日・30日(初期値)・90日・無期限から選べます。日ごと・すべてを削除できます。ログアウトすると、この iPhone に保存した移動の記録は削除されます。GPX の形で書き出したファイルは、あなたが保存した場所に残り、本アプリからは削除できません。
  • アカウントの削除: 本アプリの「設定」→「アカウントを削除」で(Apple・Google のアカウントは、その方法で本人確認をします。Apple のアカウントは、本アプリの Apple でサインインの許可も取り消します)、プロフィール、ログイン用のアカウント、位置、あなたが送ったメッセージ、ブロック一覧を削除し、つながりを解除して、そこからあなたの表示名を消します(相手の画面には「削除されたユーザー」と表示されます)。この iPhone の移動の記録も削除します。
  • 残る可能性のある情報: iPhone がオフラインだった、またはアプリを開かなかった場合、解除されたつながりにあなたが送ったメッセージは、毎日の自動の掃除まで、誰にも読めない状態でサーバーに残ることがあります。
