PDF Too Big to Send? Compress, Split or Extract Pages

Updated: October 9, 2026

You try to send a PDF and get “file too large,” or it exceeds the upload limit on an application form. It is a common problem with scanned documents and photo-heavy materials. This article explains three ways to bring a heavy PDF down to a sendable size, and how to choose between them.

In short, use “compress” if you must send every page in one file, “extract pages” if only some pages are needed, and “split” if it is fine to send in several parts. Compressing rebuilds pages as images, so text can no longer be searched or copied.

Why Does a PDF Get Too Heavy to Send?

A PDF made from a scan or photos holds each whole page as a large image, so the file grows with the page count. Email attachments, chat apps and application-form uploads all have size limits, and you cannot send anything above them. The limit differs by destination, so check the recipient's instructions first.

How Do the Three Ways to Lighten a PDF Differ?

MethodBest whenWhat to know
Compress PDFYou must send every page in one filePages are rebuilt as images, so quality drops and text can no longer be searched or copied
Extract pagesThe recipient only needs some pagesYou get a new PDF of just the pages you pick. Quality does not change
Split PDFYou can send it in several emails or filesIt splits evenly by “Pages per file.” You cannot cut out a page range

With every method, your original PDF stays as it is, and the result is added to your library as a new document.

How Do I Lighten It With “Compress”?

  1. In PDF Toolkit, open “Tools” (the wrench icon) at the top right of the Library screen
  2. Tap “Compress PDF” and pick the PDF you want to make lighter
  3. When it finishes, a document whose name starts with “Compressed PDF” is added to your library
  4. Check the page count and file size shown on the document screen
  5. Use “Share” to attach it to an email or chat message and send it

You cannot choose the strength of compression. It rebuilds each page as an image about 60% of its original size. A PDF that already contains many images tends to get lighter, but depending on the content it may not shrink as much as you expect. Compare the original file's size (you can check it in a file manager app) with the size shown on the document screen after compressing.

After compressing, check that the text is readable and that charts and figures are not smudged. Compressing discards the text data, so search and copy no longer work. For a PDF you want to keep searchable, leave it uncompressed and compress only a copy to send.

How Do I Keep Only the Pages I Need With “Extract Pages”?

  1. Open “Extract pages” under Tools and pick the PDF (all pages start out selected)
  2. Tap “Deselect all,” then check the pages you need
  3. Tap “Extract N pages”

A new PDF with only the pages you chose is added. Page quality does not change, so it suits cases where you do not want to lose image quality. See How to Rotate and Extract PDF Pages for more.

How Do I Break It Into Several Files With “Split”?

  1. Open “Split PDF” under Tools and pick the PDF
  2. Enter the number of pages you want in each file under “Pages per file”
  3. Tap the confirm button, and several documents such as “Split PDF 1” and “Split PDF 2” are added

For example, entering “10” for a 30-page PDF gives three PDFs of 10 pages each. If it does not divide evenly, only the last file is shorter. Because splitting divides evenly, use “Extract pages” when you want to pick specific pages.

When Does Combining Methods Work Well?

  • When you know which pages the recipient needs: first remove the unneeded pages with “Extract pages,” and if it is still too heavy, apply “Compress”
  • When you are sending every page but it will not fit in one message: break it up with “Split” and send it in several emails

What Should I Check Before Sending?

  • The destination's size limit: email, chat and application forms differ. Compare it with the file size on the document screen before you send
  • Readability after compressing: zoom in and check that text, numbers and charts are legible
  • The free version's watermark: PDFs you share or send carry a small “Created with PDF Toolkit” at the bottom of each page. To remove it, use “Export without watermark” (watching one video ad covers that PDF once) or the PRO version (one-time purchase)

Summary

For a PDF too big to send, “compress” if you must send every page, “extract pages” if some will do, and “split” if you can send it in parts. Compressing affects image quality and text search, so always check the result before you send. Your original PDF remains, so you can try another method if one does not work.

Frequently Asked Questions

Q. How much smaller does compressing make a PDF?

A. It depends on the PDF's content, and it may not shrink as much as you expect. PDFs with many images tend to get lighter. Check the file size shown on the document screen after compressing.

Q. Can I choose how strongly it compresses?

A. No. PDF Toolkit's compression rebuilds each page as an image about 60% of its original size.

Q. Can I search or copy text in a compressed PDF?

A. No. Compression rebuilds pages as images, so no text data remains. Keep the PDF you want to search uncompressed, and compress only a copy to send.

Q. Does compressing or extracting delete my original PDF?

A. No. The result is added to your library as a new document, and your original PDF stays as it is.

Q. How many pages can each file have when I split a PDF?

A. Enter any number of 1 or more under “Pages per file” and the PDF is divided into files of that many pages. If it does not divide evenly, the last file has fewer pages.
