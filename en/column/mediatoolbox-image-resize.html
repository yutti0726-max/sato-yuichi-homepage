How to Resize an Image to Any Size | Specify Width & Height on Your Phone

Updated: September 7, 2026

An application form asks for "an image no wider than 800px," or a photo is too large to upload. Being able to freely specify an image's width and height in pixels comes in handy in situations like these. This article explains how to resize an image using only a phone app.

In short, the free app MediaToolbox lets you resize an image by specifying width and height in pixels, and you can also specify just one dimension while keeping the aspect ratio locked.

When Would I Need to Resize an Image?

  • Matching a size required by a form or system: often specified in pixels, like "no wider than ◯px"
  • Shrinking the file size: a photo shot on a phone is high-resolution and heavy as-is
  • Making it small for a thumbnail: uniform image sizes for a list view
  • Matching a social media or blog's recommended size: balancing quality and file size to fit the destination

How Do I Resize an Image in MediaToolbox?

  1. Open MediaToolbox and select "Resize Image"
  2. Choose the image you want to resize
  3. Specify width and height in pixels (you can also specify just one, keeping the aspect ratio locked)
  4. Running the resize saves the image at the specified size to your device
Specifying only the width or only the height with the aspect-ratio-lock setting on lets you resize without stretching or distorting the image, keeping the correct proportions. If you're not sure of the required size, check the destination's instructions or the form's notes beforehand to avoid redoing the work.

Resize or Format Conversion — Which Should I Use?

Even though the goal might be the same — "shrink the file size" — the feature you need differs depending on whether you're changing the image's "size" (pixel dimensions) or its "format" (JPEG/PNG/WEBP). If you want to keep the photo's actual size but just change the format, use image format conversion; if you want to shrink the pixel dimensions themselves, use this resize feature. Combining both can shrink the file size even further.

Summary

Resizing an image is useful across a wide range of situations, from matching a size required by an application form to everyday file-size reduction. No computer needed — just specify width and height in a phone app, and the resize is done on the spot.

Frequently Asked Questions

Q. Does resizing an image also shrink the file size?

A. Yes. Generally, the smaller you make the width and height in pixels, the smaller the file size becomes as well.

Q. What happens to the aspect ratio?

A. Specifying just the width or just the height also supports a setting that automatically calculates the other dimension while keeping the aspect ratio locked. There's no need to worry about the image looking stretched or distorted.

Q. Can I make an image larger than its specified pixel size?

A. Enlarging is possible, but stretching an image significantly larger than the original can make it look grainy. How far you can go depends on the original image's resolution.

Q. Can I resize multiple images at once?

A. Yes, selecting multiple images when choosing which to resize lets you resize them all to the same size at once.

Q. Does resizing overwrite the original image?

A. No. The resized image is saved as a new file, so the original image is left untouched.
